# Supermarket Management Frontend — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Vietnamese-language web frontend for a mini-supermarket management system — fifteen screens covering F1–F10 — against an existing, contract-stable REST API, developed entirely against a stateful mock so frontend and backend can be built separately and integrated later.

**Architecture:** A client-side React application inside Next.js App Router. All data fetching happens in the browser through one typed client (`openapi-fetch` over the already-generated `paths` type) wrapped in TanStack Query. MSW intercepts at the network boundary with a stateful in-memory backend that implements BR1–BR11, so the demo is real rather than canned. Nothing outside `lib/api` knows HTTP, tokens, or error codes exist; switching to the live backend is one environment variable.

**Tech Stack:** Next.js 15 (App Router), TypeScript (strict), Tailwind CSS 4, shadcn/ui, TanStack Query 5, `openapi-fetch`, MSW 2, react-hook-form + zod, Recharts, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-20-supermarket-frontend-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- **Working directory is `/home/karpy/Lab/m1/frontend/`.** All paths in this plan are relative to it unless prefixed with `m1/`.
- **Node 20+.** Next.js 15, React 19, TypeScript `strict: true`.
- **All user-facing text is Vietnamese.** No English in the UI, including empty states, buttons, and error messages.
- **`m1/api-types.ts` is generated by `openapi-typescript` and must never be edited.** It is imported type-only via the `@contract` path alias. The backend developer regenerates it; a regeneration that breaks the build is the intended early-warning signal.
- **Money is VND, whole numbers in practice.** Never render a raw number — always `<Money>`. Never do float arithmetic for display.
- **All server timestamps are UTC ISO-8601.** Never render a raw timestamp — always `<DateTime>`, which converts to `Asia/Ho_Chi_Minh`. Date filters are sent as `YYYY-MM-DD` in store-local time.
- **UI logic branches on `AppError.code`, never on `message`.** The server's `message` is Vietnamese and displayable, but behavior keys off the code.
- **Mutations never auto-retry.** TanStack Query `retry: false` for all mutations. `POST /sales` has no server-side idempotency key; a retry on timeout double-charges a customer.
- **Search inputs are capped at 100 characters (30 for document-number searches) and whitespace-only input issues no request.**
- **Report ranges require both `from` and `to`, `to` is inclusive, and the span must not exceed 366 days.** Validated client-side before the request.
- **Role gating is UX, not security.** Every screen renders a sane state on `403`.
- **`costPrice` and `unitCostSnapshot` are never rendered for a `CASHIER`.**
- **Nothing outside `src/lib/api/` imports `fetch`, axios, or references a token.**
- **The mock is active only when `NEXT_PUBLIC_API_MODE=mock`.**
- Commit after every task. Conventional commit messages (`feat:`, `test:`, `chore:`).

## Review Focus

Five failure modes the spec implies but which no screen-level task would naturally exercise. Each has a test pinned to the task that owns the code.

1. **Two requests receive `401` at the same moment.** The refresh token is one-time-use with reuse detection; two concurrent `/auth/refresh` calls revoke the entire session and eject the cashier mid-sale. Exactly one refresh may ever be in flight. → Task 4.
2. **A sale recorded at 00:30 store time displays on the wrong business day.** `2026-10-20T17:30:00Z` is 21/10/2026 00:30 in `Asia/Ho_Chi_Minh`; a naive renderer shows 20/10. → Task 2.
3. **A user pastes 150 characters into a search box, or types only spaces.** The contract caps search at 100 characters and ignores whitespace-only; sending it raw produces spurious `400`s. → Task 11.
4. **A report range where `to` precedes `from`, or spans more than 366 days.** Must be refused client-side with a Vietnamese message, not round-tripped into a `400`. → Task 21.
5. **A cashier navigates directly to `/reports/revenue` by URL.** Hiding the nav item does not prevent this; the screen must render "Không có quyền truy cập", not crash or show an empty chart. → Task 8.

```ts
export const STORE_TIME_ZONE = "Asia/Ho_Chi_Minh";

const dateTimeFormatter = new Intl.DateTimeFormat("en-GB", {
  timeZone: STORE_TIME_ZONE,
  day: "2-digit",
  month: "2-digit",
  year: "numeric",
  hour: "2-digit",
  minute: "2-digit",
  hour12: false,
});

const dateFormatter = new Intl.DateTimeFormat("en-GB", {
  timeZone: STORE_TIME_ZONE,
  day: "2-digit",
  month: "2-digit",
  year: "numeric",
});

/** "21/10/2026 00:30" in store time. Always use this for server timestamps. */
export function formatStoreDateTime(isoUtc: string): string {
  // en-GB yields "21/10/2026, 00:30" — drop the comma for a compact cell.
  return dateTimeFormatter.format(new Date(isoUtc)).replace(",", "");
}

/** "21/10/2026" in store time. */
export function formatStoreDate(isoUtc: string): string {
  return dateFormatter.format(new Date(isoUtc));
}

/** "YYYY-MM-DD" in store time, for `from`/`to` query parameters. */
export function toStoreDateString(date: Date): string {
  // en-CA renders ISO-style YYYY-MM-DD.
  return new Intl.DateTimeFormat("en-CA", { timeZone: STORE_TIME_ZONE }).format(date);
}

/** Inclusive day span between two YYYY-MM-DD strings. Negative when `to` precedes `from`. */
export function daysBetween(from: string, to: string): number {
  const MS_PER_DAY = 86_400_000;
  const start = Date.parse(`${from}T00:00:00Z`);
  const end = Date.parse(`${to}T00:00:00Z`);
  const diff = Math.round((end - start) / MS_PER_DAY);
  return diff >= 0 ? diff + 1 : diff;
}
```

```ts
import type { ErrorCode } from "./types";

export class AppError extends Error {
  readonly code: ErrorCode;
  readonly status: number;
  readonly details: unknown;

  constructor(code: ErrorCode, message: string, status: number, details?: unknown) {
    super(message);
    this.name = "AppError";
    this.code = code;
    this.status = status;
    this.details = details;
  }
}

const GENERIC_MESSAGE = "Đã xảy ra lỗi. Vui lòng thử lại.";

function readEnvelope(body: unknown): { code?: string; message?: string; details?: unknown } | null {
  if (typeof body !== "object" || body === null) return null;
  const error = (body as Record<string, unknown>).error;
  if (typeof error !== "object" || error === null) return null;
  return error as { code?: string; message?: string; details?: unknown };
}

/**
 * Turns any failed response into a typed AppError.
 * UI logic must branch on `code` — never on `message`.
 */
export function normalizeError(status: number, body: unknown): AppError {
  const envelope = readEnvelope(body);

  if (envelope?.code) {
    return new AppError(
      envelope.code as ErrorCode,
      envelope.message ?? GENERIC_MESSAGE,
      status,
      envelope.details,
    );
  }

  if (status === 0) {
    return new AppError("SERVICE_UNAVAILABLE", "Không kết nối được máy chủ.", 0);
  }

  return new AppError("INTERNAL_ERROR", GENERIC_MESSAGE, status);
}

export function isCode(error: unknown, code: ErrorCode): error is AppError {
  return error instanceof AppError && error.code === code;
}
```

```ts
import { AppError } from "./errors";
import type { UserResponse } from "./types";

export type Session = {
  accessToken: string;
  refreshToken: string;
  user: UserResponse;
};

const STORAGE_KEY = "mini-store.session";

let current: Session | null = null;
let inFlight: Promise<Session> | null = null;
const listeners = new Set<(s: Session | null) => void>();

function notify() {
  for (const fn of listeners) fn(current);
}

export function getSession(): Session | null {
  if (current) return current;
  if (typeof window === "undefined") return null;
  const raw = window.localStorage.getItem(STORAGE_KEY);
  if (!raw) return null;
  try {
    current = JSON.parse(raw) as Session;
    return current;
  } catch {
    window.localStorage.removeItem(STORAGE_KEY);
    return null;
  }
}

export function setSession(session: Session): void {
  current = session;
  if (typeof window !== "undefined") {
    window.localStorage.setItem(STORAGE_KEY, JSON.stringify(session));
  }
  notify();
}

export function clearSession(): void {
  current = null;
  inFlight = null;
  if (typeof window !== "undefined") {
    window.localStorage.removeItem(STORAGE_KEY);
  }
  notify();
}

export function subscribeToSession(fn: (s: Session | null) => void): () => void {
  listeners.add(fn);
  return () => listeners.delete(fn);
}

/**
 * Runs at most one refresh at a time.
 *
 * The API's refresh token is single-use with reuse detection: two concurrent
 * /auth/refresh calls look like a stolen token and revoke the whole session.
 * Every caller that arrives while a refresh is running awaits the same promise.
 */
export function refreshOnce(
  refreshFn: (refreshToken: string) => Promise<Session>,
): Promise<Session> {
  if (inFlight) return inFlight;

  const session = getSession();
  if (!session) {
    return Promise.reject(
      new AppError("UNAUTHENTICATED", "Phiên đăng nhập đã kết thúc.", 401),
    );
  }

  inFlight = refreshFn(session.refreshToken)
    .then((next) => {
      setSession(next);
      return next;
    })
    .catch((error) => {
      clearSession();
      throw error;
    })
    .finally(() => {
      inFlight = null;
    });

  return inFlight;
}
```

Note the ordering in `clearSession`: it nulls `inFlight` so a failed refresh cannot wedge the gate shut — the fourth test covers exactly that.

```ts
import createClient, { type Middleware } from "openapi-fetch";
import type { paths } from "./types";
import { normalizeError, AppError } from "./errors";
import {
  getSession,
  setSession,
  clearSession,
  refreshOnce,
  type Session,
} from "./session";

const BASE_URL = process.env.NEXT_PUBLIC_API_BASE_URL ?? "http://localhost:3001";

export const api = createClient<paths>({ baseUrl: BASE_URL });

/** Raw client without the auth middleware, used for login and refresh. */
const bare = createClient<paths>({ baseUrl: BASE_URL });

async function refreshRequest(refreshToken: string): Promise<Session> {
  const { data, error, response } = await bare.POST("/api/v1/auth/refresh", {
    body: { refreshToken },
  });
  if (error || !data) throw normalizeError(response.status, error);
  const payload = (data as { data: { accessToken: string; refreshToken: string; user: Session["user"] } }).data;
  return { accessToken: payload.accessToken, refreshToken: payload.refreshToken, user: payload.user };
}

const authMiddleware: Middleware = {
  async onRequest({ request }) {
    const session = getSession();
    if (session) request.headers.set("Authorization", `Bearer ${session.accessToken}`);
    return request;
  },

  async onResponse({ request, response }) {
    if (response.status !== 401) return response;
    // Never try to refresh a refresh.
    if (request.url.includes("/auth/refresh") || request.url.includes("/auth/login")) {
      return response;
    }

    try {
      const next = await refreshOnce(refreshRequest);
      const replay = request.clone();
      replay.headers.set("Authorization", `Bearer ${next.accessToken}`);
      return await fetch(replay);
    } catch {
      clearSession();
      return response;
    }
  },
};

api.use(authMiddleware);

type ApiResult<T> = { data?: { data: T }; error?: unknown; response: Response };

/** Unwraps the `{ data: ... }` envelope, throwing a typed AppError on failure. */
export function unwrap<T>(result: ApiResult<T>): T {
  if (result.error || !result.data) {
    throw normalizeError(result.response?.status ?? 0, result.error);
  }
  return result.data.data;
}

export async function login(username: string, password: string): Promise<Session> {
  const { data, error, response } = await bare.POST("/api/v1/auth/login", {
    body: { username, password },
  });
  if (error || !data) throw normalizeError(response.status, error);
  const payload = (data as { data: { accessToken: string; refreshToken: string; user: Session["user"] } }).data;
  const session = {
    accessToken: payload.accessToken,
    refreshToken: payload.refreshToken,
    user: payload.user,
  };
  setSession(session);
  return session;
}

export async function logout(): Promise<void> {
  try {
    await api.POST("/api/v1/auth/logout", {});
  } catch {
    // Logging out locally must succeed even if the server call fails.
  } finally {
    clearSession();
  }
}

export { AppError };
```

```ts
import { toStoreDateString } from "@/lib/format/datetime";
import type { Role } from "@/lib/api/types";

/**
 * BR7 — an invoice discount is split across lines in proportion to each line's
 * subtotal, rounded to whole dong, with the final line absorbing the remainder
 * so the parts always sum back to the discount.
 */
export function allocateDiscount(lineSubtotals: number[], discount: number): number[] {
  if (discount <= 0 || lineSubtotals.length === 0) {
    return lineSubtotals.map(() => 0);
  }

  const subtotal = lineSubtotals.reduce((a, b) => a + b, 0);
  if (subtotal <= 0) return lineSubtotals.map(() => 0);

  const parts = lineSubtotals.map((line) => Math.round((discount * line) / subtotal));
  const allocated = parts.slice(0, -1).reduce((a, b) => a + b, 0);
  parts[parts.length - 1] = discount - allocated;
  return parts;
}

/** BR6 — one point per 10.000 VND of the post-discount total, rounded down. */
export function computePoints(total: number): number {
  return Math.floor(total / 10_000);
}

/** BR11 — weighted average cost on goods receipt, to two decimals. */
export function weightedAverageCost(
  oldQty: number,
  oldCost: number,
  inQty: number,
  inCost: number,
): number {
  if (oldQty <= 0) return inCost;
  const blended = (oldQty * oldCost + inQty * inCost) / (oldQty + inQty);
  return Math.round(blended * 100) / 100;
}

const DISCOUNT_CEILING: Record<Role, number> = {
  ADMIN: 1,
  CASHIER: 0.1,
  STOCKKEEPER: 0,
};

/** BR7 — the maximum discount this role may apply to a given subtotal. */
export function maxDiscountFor(role: Role, subtotal: number): number {
  return Math.floor(subtotal * DISCOUNT_CEILING[role]);
}

/** `HD`/`PN`/`KK` + store-local yyyyMMdd + a sequence padded to at least 4 digits. */
export function nextDocumentNumber(
  prefix: "HD" | "PN" | "KK",
  date: Date,
  sequence: number,
): string {
  const day = toStoreDateString(date).replaceAll("-", "");
  return `${prefix}${day}${String(sequence).padStart(4, "0")}`;
}
```

```ts
import { HttpResponse, delay } from "msw";
import { db } from "../db";
import type { Role } from "@/lib/api/types";

export const BASE = "*/api/v1";

/** Mirrors the real latency band so loading states are built honestly. */
export async function simulateLatency() {
  await delay(150 + Math.random() * 250);
}

export function ok(data: unknown, status = 200) {
  return HttpResponse.json({ data }, { status });
}

export function fail(status: number, code: string, message: string, details?: unknown) {
  return HttpResponse.json({ error: { code, message, details } }, { status });
}

export class HandlerError extends Error {
  constructor(readonly response: Response) {
    super("handler error");
  }
}

/** Resolves the acting user from the bearer token, or throws a 401/403 response. */
export function actingUser(request: Request, allowed?: Role[]) {
  const header = request.headers.get("authorization") ?? "";
  const token = header.replace("Bearer ", "");
  const entry = db.tokens[token];

  if (!entry || entry.expiresAt < Date.now()) {
    throw new HandlerError(fail(401, "UNAUTHENTICATED", "Phiên đăng nhập đã hết hạn."));
  }

  const user = db.users.find((u) => u.id === entry.userId);
  if (!user || !user.isActive) {
    throw new HandlerError(fail(403, "ACCOUNT_LOCKED", "Tài khoản đã bị khóa."));
  }
  if (allowed && !allowed.includes(user.role)) {
    throw new HandlerError(fail(403, "FORBIDDEN", "Không có quyền truy cập chức năng này."));
  }
  return user;
}

/** Wraps a resolver so a thrown HandlerError becomes its response. */
export function guard<T extends (...args: never[]) => Promise<Response> | Response>(fn: T): T {
  return (async (...args: Parameters<T>) => {
    try {
      return await fn(...args);
    } catch (e) {
      if (e instanceof HandlerError) return e.response;
      throw e;
    }
  }) as T;
}

/** Forces the next matching request to fail. Demo and manual-testing aid only. */
let forcedFailure: { code: string; status: number; message: string } | null = null;

export function setForcedFailure(next: typeof forcedFailure) {
  forcedFailure = next;
}

export function takeForcedFailure(): Response | null {
  if (!forcedFailure) return null;
  const { status, code, message } = forcedFailure;
  forcedFailure = null; // fires once, then clears
  return fail(status, code, message);
}
```

Create `src/mocks/handlers/auth.ts`. The access token deliberately lives 60 seconds so the single-flight refresh from Task 4 is exercised constantly during development:

```ts
import { http } from "msw";
import { db, persist } from "../db";
import { BASE, ok, fail, simulateLatency, actingUser, guard, takeForcedFailure } from "./_shared";

const ACCESS_TTL_MS = 60_000;
const REFRESH_TTL_MS = 7 * 24 * 60 * 60 * 1000;

let tokenCounter = 0;
function issue(userId: number, ttl: number) {
  const token = `tok-${++tokenCounter}-${Math.random().toString(36).slice(2)}`;
  db.tokens[token] = { userId, expiresAt: Date.now() + ttl };
  persist();
  return token;
}

function publicUser(u: (typeof db.users)[number]) {
  const { password: _password, ...rest } = u;
  return rest;
}

export const authHandlers = [
  http.post(`${BASE}/auth/login`, async ({ request }) => {
    await simulateLatency();
    const { username, password } = (await request.json()) as { username: string; password: string };

    const user = db.users.find((u) => u.username === username.toLowerCase());
    if (!user || user.password !== password) {
      return fail(401, "INVALID_CREDENTIALS", "Tên đăng nhập hoặc mật khẩu không đúng.");
    }
    if (!user.isActive) {
      return fail(403, "ACCOUNT_LOCKED", "Tài khoản đã bị khóa. Vui lòng liên hệ quản lý.");
    }

    return ok({
      accessToken: issue(user.id, ACCESS_TTL_MS),
      refreshToken: issue(user.id, REFRESH_TTL_MS),
      expiresIn: ACCESS_TTL_MS / 1000,
      user: publicUser(user),
    });
  }),

  http.post(`${BASE}/auth/refresh`, async ({ request }) => {
    await simulateLatency();
    const { refreshToken } = (await request.json()) as { refreshToken: string };
    const entry = db.tokens[refreshToken];

    if (!entry || entry.expiresAt < Date.now()) {
      return fail(401, "INVALID_REFRESH_TOKEN", "Phiên đăng nhập không còn hiệu lực.");
    }

    // Single-use with rotation: the old token dies here. Replaying it fails.
    delete db.tokens[refreshToken];
    const user = db.users.find((u) => u.id === entry.userId)!;

    return ok({
      accessToken: issue(user.id, ACCESS_TTL_MS),
      refreshToken: issue(user.id, REFRESH_TTL_MS),
      expiresIn: ACCESS_TTL_MS / 1000,
      user: publicUser(user),
    });
  }),

  http.get(`${BASE}/auth/me`, guard(async ({ request }) => {
    await simulateLatency();
    return ok(publicUser(actingUser(request)));
  })),

  http.post(`${BASE}/auth/logout`, guard(async ({ request }) => {
    const header = request.headers.get("authorization") ?? "";
    delete db.tokens[header.replace("Bearer ", "")];
    persist();
    return ok({ success: true });
  })),
];
```

```tsx
  const [session, setSessionState] = useState<Session | null>(null);

  useEffect(() => {
    setSessionState(getSession());
    return subscribeToSession(setSessionState);
  }, []);

  const value = useMemo<AuthValue>(
    () => ({
      user: session?.user ?? null,
      isAuthenticated: Boolean(session),
      async login(username, password) {
        const next = await apiLogin(username, password);
        router.push(homeRouteFor(next.user.role));
      },
      async logout() {
        await apiLogout();
        router.push("/login");
      },
    }),
    [session, router],
  );

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth(): AuthValue {
  const value = useContext(AuthContext);
  if (!value) throw new Error("useAuth must be used inside <AuthProvider>");
  return value;
}
```

```ts
import type { QueryClient } from "@tanstack/react-query";
import { qk } from "./keys";

export type MutationName =
  | "createSale"
  | "createPurchase" | "updatePurchase" | "receivePurchase" | "cancelPurchase"
  | "createStockCount"
  | "mutateProduct" | "mutateCategory" | "mutateSupplier" | "mutateCustomer" | "mutateUser";

/**
 * What becomes stale after each mutation.
 * Receiving a purchase changes both quantity and weighted-average cost,
 * so products must be invalidated alongside inventory.
 */
export const INVALIDATION_MAP: Record<MutationName, readonly (readonly unknown[])[]> = {
  createSale: [qk.inventory.all(), qk.sales.all(), qk.customers.all(), qk.products.all()],
  createPurchase: [qk.purchases.all()],
  updatePurchase: [qk.purchases.all()],
  receivePurchase: [qk.purchases.all(), qk.inventory.all(), qk.products.all()],
  cancelPurchase: [qk.purchases.all()],
  createStockCount: [qk.inventory.all(), qk.products.all()],
  mutateProduct: [qk.products.all(), qk.inventory.all()],
  mutateCategory: [qk.categories.all(), qk.products.all()],
  mutateSupplier: [qk.suppliers.all()],
  mutateCustomer: [qk.customers.all()],
  mutateUser: [qk.users.all()],
};

export async function invalidateFor(client: QueryClient, mutation: MutationName): Promise<void> {
  await Promise.all(
    INVALIDATION_MAP[mutation].map((queryKey) =>
      client.invalidateQueries({ queryKey: queryKey as unknown[] }),
    ),
  );
}
```

```ts
export const SEARCH_MAX = 100;
export const DOCUMENT_SEARCH_MAX = 30;

/**
 * The contract caps search at 100 characters (30 for document numbers) and
 * ignores whitespace-only input. Sending raw input produces spurious 400s.
 * Returns undefined when no search parameter should be sent at all.
 */
export function normalizeSearch(raw: string, maxLength: number = SEARCH_MAX): string | undefined {
  const trimmed = raw.trim();
  if (trimmed.length === 0) return undefined;
  return trimmed.slice(0, maxLength);
}
```

```tsx
"use client";

import { useState } from "react";
import type { UseQueryResult } from "@tanstack/react-query";
import { AppError } from "@/lib/api/errors";
import { normalizeSearch, SEARCH_MAX } from "./searchInput";

export type Column<T> = {
  key: string;
  header: string;
  render: (row: T) => React.ReactNode;
  className?: string;
};

export type ListResult<T> = { items: T[]; meta: { page: number; pageSize: number; total: number } };

type Props<T> = {
  columns: Column<T>[];
  query: UseQueryResult<ListResult<T>, unknown>;
  search: string;
  onSearchChange: (value: string) => void;
  searchPlaceholder?: string;
  searchMaxLength?: number;
  filters?: React.ReactNode;
  actions?: React.ReactNode;
  page: number;
  onPageChange: (page: number) => void;
  emptyMessage?: string;
  onRowClick?: (row: T) => void;
};

export function DataTable<T extends { id: number }>({
  columns, query, search, onSearchChange, searchPlaceholder = "Tìm kiếm…",
  searchMaxLength = SEARCH_MAX, filters, actions, page, onPageChange,
  emptyMessage = "Không có dữ liệu", onRowClick,
}: Props<T>) {
  const { data, isLoading, error } = query;

  if (error instanceof AppError && error.code === "FORBIDDEN") {
    return (
      <div className="rounded-lg border bg-white py-20 text-center">
        <h2 className="font-semibold">Không có quyền truy cập</h2>
        <p className="mt-1 text-sm text-slate-500">
          Tài khoản của bạn không được phép xem danh sách này.
        </p>
      </div>
    );
  }

  const totalPages = data ? Math.max(1, Math.ceil(data.meta.total / data.meta.pageSize)) : 1;

  return (
    <div className="space-y-4">
      <div className="flex flex-wrap items-center gap-2">
        <input
          type="search"
          aria-label="Tìm kiếm"
          placeholder={searchPlaceholder}
          maxLength={searchMaxLength}
          value={search}
          onChange={(e) => onSearchChange(e.target.value)}
          className="w-64 rounded-md border px-3 py-2"
        />
        {filters}
        <div className="ml-auto">{actions}</div>
      </div>

      <div className="overflow-x-auto rounded-lg border bg-white">
        <table className="w-full text-sm">
          <thead className="bg-slate-50 text-left">
            <tr>
              {columns.map((c) => (
                <th key={c.key} className={`px-3 py-2 font-medium ${c.className ?? ""}`}>{c.header}</th>
              ))}
            </tr>
          </thead>
          <tbody>
            {isLoading &&
              Array.from({ length: 5 }).map((_, i) => (
                <tr key={`skeleton-${i}`} className="border-t">
                  {columns.map((c) => (
                    <td key={c.key} className="px-3 py-3">
                      <div className="h-4 w-full animate-pulse rounded bg-slate-200" />
                    </td>
                  ))}
                </tr>
              ))}

            {!isLoading && data?.items.length === 0 && (
              <tr>
                <td colSpan={columns.length} className="px-3 py-16 text-center text-slate-500">
                  {emptyMessage}
                </td>
              </tr>
            )}

            {!isLoading &&
              data?.items.map((row) => (
                <tr
                  key={row.id}
                  onClick={onRowClick ? () => onRowClick(row) : undefined}
                  className={`border-t ${onRowClick ? "cursor-pointer hover:bg-slate-50" : ""}`}
                >
                  {columns.map((c) => (
                    <td key={c.key} className={`px-3 py-2 ${c.className ?? ""}`}>{c.render(row)}</td>
                  ))}
                </tr>
              ))}
          </tbody>
        </table>
      </div>

      {data && data.meta.total > data.meta.pageSize && (
        <div className="flex items-center justify-between text-sm">
          <span className="text-slate-500">
            Trang {data.meta.page} / {totalPages} — {data.meta.total} bản ghi
          </span>
          <div className="flex gap-2">
            <button
              disabled={page <= 1} onClick={() => onPageChange(page - 1)}
              className="rounded-md border px-3 py-1 disabled:opacity-40"
            >Trước</button>
            <button
              disabled={page >= totalPages} onClick={() => onPageChange(page + 1)}
              className="rounded-md border px-3 py-1 disabled:opacity-40"
            >Sau</button>
          </div>
        </div>
      )}
    </div>
  );
}

export { normalizeSearch };
```

```ts
import { AppError } from "@/lib/api/errors";

type FieldIssue = { field: string; messages: string[] };

/**
 * Routes a server error onto form fields where possible.
 * Returns a form-level message when the error is not attributable to a field,
 * or null when every part of it was placed on a field.
 */
export function applyServerErrors(
  error: unknown,
  setError: (field: string, e: { message: string }) => void,
): string | null {
  if (!(error instanceof AppError)) {
    return "Đã xảy ra lỗi. Vui lòng thử lại.";
  }

  if (error.code === "VALIDATION_ERROR" && Array.isArray(error.details)) {
    for (const issue of error.details as FieldIssue[]) {
      if (issue?.field && issue.messages?.length) {
        setError(issue.field, { message: issue.messages[0] });
      }
    }
    return null;
  }

  if (error.code === "DUPLICATE_VALUE") {
    const fields = (error.details as { fields?: string | string[] } | undefined)?.fields;
    const list = typeof fields === "string" ? [fields] : (fields ?? []);
    if (list.length > 0) {
      for (const field of list) setError(field, { message: error.message });
      return null;
    }
  }

  return error.message;
}
```

```ts
"use client";

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { api, unwrap } from "@/lib/api/client";
import { qk } from "@/lib/query/keys";
import { invalidateFor } from "@/lib/query/invalidation";
import type { ProductResponse } from "@/lib/api/types";

export type ProductListParams = {
  page: number;
  pageSize?: number;
  search?: string;
  categoryId?: number;
  isActive?: boolean;
};

export function useProductList(params: ProductListParams) {
  return useQuery({
    queryKey: qk.products.list(params),
    queryFn: async () =>
      unwrap<{ items: ProductResponse[]; meta: { page: number; pageSize: number; total: number } }>(
        await api.GET("/api/v1/products", {
          params: { query: { pageSize: 20, ...params } },
        }),
      ),
  });
}

export function useProductMutations() {
  const client = useQueryClient();
  const done = () => invalidateFor(client, "mutateProduct");

  const create = useMutation({
    mutationFn: async (body: Record<string, unknown>) =>
      unwrap<ProductResponse>(await api.POST("/api/v1/products", { body: body as never })),
    onSuccess: done,
  });

  const update = useMutation({
    mutationFn: async ({ id, ...body }: { id: number } & Record<string, unknown>) =>
      unwrap<ProductResponse>(
        await api.PATCH("/api/v1/products/{id}", { params: { path: { id } }, body: body as never }),
      ),
    onSuccess: done,
  });

  const setActive = useMutation({
    mutationFn: async ({ id, active }: { id: number; active: boolean }) =>
      unwrap<ProductResponse>(
        await api.POST(
          active ? "/api/v1/products/{id}/activate" : "/api/v1/products/{id}/deactivate",
          { params: { path: { id } } },
        ),
      ),
    onSuccess: done,
  });

  return { create, update, setActive };
}
```

```ts
import { db, persist, paginate, matchesSearch, nextId, nextSequence } from "../db";
import { BASE, ok, fail, simulateLatency, actingUser, guard } from "./_shared";
import { allocateDiscount, computePoints, maxDiscountFor, nextDocumentNumber } from "../rules";
import { toStoreDateString } from "@/lib/format/datetime";

type CartItem = { productId: number; quantity: number };
type PaymentInput = { method: "CASH" | "CARD" | "TRANSFER" | "OTHER"; amount: number; tenderedAmount?: number; reference?: string };

export const saleHandlers = [
  http.post(`${BASE}/sales`, guard(async ({ request }) => {
    await simulateLatency();
    const user = actingUser(request, ["ADMIN", "CASHIER"]);
    const body = (await request.json()) as {
      customerId?: number; items: CartItem[]; discountAmount?: number;
      payments: PaymentInput[]; note?: string;
    };

    // Duplicate products in the cart are merged, matching the backend.
    const merged = new Map<number, number>();
    for (const item of body.items ?? []) {
      merged.set(item.productId, (merged.get(item.productId) ?? 0) + item.quantity);
    }
    if (merged.size === 0) {
      return fail(400, "VALIDATION_ERROR", "Giỏ hàng trống.", [
        { field: "items", messages: ["Cần ít nhất một sản phẩm."] },
      ]);
    }

    // Resolve products and reject unavailable ones before touching stock.
    const lines: Array<{ product: (typeof db.products)[number]; quantity: number }> = [];
    for (const [productId, quantity] of merged) {
      if (!Number.isInteger(quantity) || quantity < 1) {
        return fail(422, "INVALID_QUANTITY", "Số lượng phải là số nguyên lớn hơn 0.");
      }
      const product = db.products.find((p) => p.id === productId);
      if (!product) return fail(404, "PRODUCT_NOT_FOUND", "Sản phẩm không tồn tại.");
      if (!product.isActive) {
        return fail(422, "PRODUCT_UNAVAILABLE", `Sản phẩm "${product.name}" đã ngừng bán.`);
      }
      lines.push({ product, quantity });
    }

    // BR1 — no negative stock. Report every shortfall at once so the cart can self-correct.
    const shortfalls = lines
      .filter((l) => l.product.stockQty < l.quantity)
      .map((l) => ({
        productId: l.product.id, sku: l.product.sku, name: l.product.name,
        requested: l.quantity, available: l.product.stockQty,
      }));
    if (shortfalls.length > 0) {
      return fail(409, "INSUFFICIENT_STOCK", "Không đủ tồn kho cho một số sản phẩm.", shortfalls);
    }

    const lineSubtotals = lines.map((l) => l.product.salePrice * l.quantity);
    const subtotal = lineSubtotals.reduce((a, b) => a + b, 0);
    const discount = Math.round(body.discountAmount ?? 0);

    // BR7 — discount must stay below subtotal and within the role ceiling.
    const ceiling = maxDiscountFor(user.role, subtotal);
    if (discount < 0 || discount >= subtotal || discount > ceiling) {
      return fail(422, "INVALID_DISCOUNT", "Mức giảm giá vượt quá hạn mức cho phép.", {
        subtotal,
        maxDiscountPercent: user.role === "ADMIN" ? 100 : 10,
        maxDiscountAmount: Math.min(ceiling, Math.max(subtotal - 1, 0)),
      });
    }

    const total = subtotal - discount;
    const paid = (body.payments ?? []).reduce((sum, p) => sum + p.amount, 0);
    if (body.payments?.length === 0 || Math.round(paid) !== total) {
      return fail(422, "INVALID_PAYMENT", "Số tiền thanh toán phải bằng đúng số tiền phải trả.", { total, paid });
    }

    // Everything validated — commit.
    const now = new Date();
    const nowIso = now.toISOString();
    const perLineDiscount = allocateDiscount(lineSubtotals, discount);
    const saleId = nextId(db.sales);
    const sequence = nextSequence(`HD-${toStoreDateString(now)}`);

    const saleItems = lines.map((l, i) => ({
      id: i + 1, productId: l.product.id,
      skuSnapshot: l.product.sku, nameSnapshot: l.product.name,
      quantity: l.quantity, unitPrice: l.product.salePrice,
      unitCostSnapshot: l.product.costPrice ?? 0,
      discountAmount: perLineDiscount[i],
      lineTotal: lineSubtotals[i] - perLineDiscount[i],
    }));

    const payments = (body.payments ?? []).map((p, i) => ({
      id: i + 1, saleId, method: p.method, amount: p.amount,
      tenderedAmount: p.tenderedAmount ?? p.amount,
      changeAmount: Math.max(0, (p.tenderedAmount ?? p.amount) - p.amount),
      paidAt: nowIso, reference: p.reference,
    }));

    const customer = body.customerId ? db.customers.find((c) => c.id === body.customerId) : undefined;
    const pointsEarned = customer ? computePoints(total) : 0;
    if (customer) {
      customer.loyaltyPoints += pointsEarned;
    }

    for (const line of lines) {
      line.product.stockQty -= line.quantity;
      db.movements.push({
        id: nextId(db.movements), productId: line.product.id, type: "SALE",
        quantity: -line.quantity, referenceType: "SALE", referenceId: saleId,
        createdBy: user.id, createdAt: nowIso,
      });
    }

    const sale = {
      id: saleId,
      invoiceNo: nextDocumentNumber("HD", now, sequence),
      customerId: customer?.id ?? null, cashierId: user.id, status: "PAID" as const,
      subtotal, discountAmount: discount, total, pointsEarned,
      soldAt: nowIso, items: saleItems, payments,
    };
    db.sales.push(sale as never);
    persist();

    return ok({ ...sale, customer: customer ?? null }, 201);
  })),

  http.get(`${BASE}/sales`, guard(async ({ request }) => {
    await simulateLatency();
    actingUser(request, ["ADMIN", "CASHIER"]);
    const url = new URL(request.url);
    let rows = [...db.sales].sort((a, b) => b.soldAt.localeCompare(a.soldAt));

    const search = url.searchParams.get("search");
    if (search) rows = rows.filter((s) => matchesSearch([s.invoiceNo], search));
    const method = url.searchParams.get("paymentMethod");
    if (method) rows = rows.filter((s) => s.payments.some((p) => p.method === method));
    const cashierId = url.searchParams.get("cashierId");
    if (cashierId) rows = rows.filter((s) => s.cashierId === Number(cashierId));

    const enriched = rows.map((s) => ({
      ...s,
      customer: s.customerId ? db.customers.find((c) => c.id === s.customerId) ?? null : null,
      cashier: db.users.find((u) => u.id === s.cashierId),
    }));
    const { items, meta } = paginate(enriched, Number(url.searchParams.get("page") ?? 1), 20);
    return ok({ items, meta });
  })),

  http.get(`${BASE}/sales/:id`, guard(async ({ request, params }) => {
    await simulateLatency();
    actingUser(request, ["ADMIN", "CASHIER"]);
    const sale = db.sales.find((s) => s.id === Number(params.id));
    if (!sale) return fail(404, "SALE_NOT_FOUND", "Không tìm thấy hóa đơn.");

      customer: sale.customerId ? db.customers.find((c) => c.id === sale.customerId) ?? null : null,
```

```ts
"use client";

import { useCallback, useMemo, useState } from "react";
import type { ProductResponse } from "@/lib/api/types";

export type CartLine = {
  productId: number;
  sku: string;
  name: string;
  unit: string;
  unitPrice: number;
  quantity: number;
  availableAtScan: number;
};

export const MAX_CART_LINES = 200;

export function useCart() {
  const [lines, setLines] = useState<CartLine[]>([]);

  const addProduct = useCallback((product: ProductResponse, quantity = 1) => {
    setLines((current) => {
      const existing = current.find((l) => l.productId === product.id);
      if (existing) {
        return current.map((l) =>
          l.productId === product.id ? { ...l, quantity: l.quantity + quantity } : l,
        );
      }
      if (current.length >= MAX_CART_LINES) return current;
      return [
        ...current,
        {
          productId: product.id, sku: product.sku, name: product.name, unit: product.unit,
          unitPrice: product.salePrice, quantity, availableAtScan: product.stockQty,
        },
      ];
    });
  }, []);

  const setQuantity = useCallback((productId: number, quantity: number) => {
    // v1 sells whole units only (BR4) — ignore anything else.
    if (!Number.isInteger(quantity)) return;
    setLines((current) =>
      quantity <= 0
        ? current.filter((l) => l.productId !== productId)
        : current.map((l) => (l.productId === productId ? { ...l, quantity } : l)),
    );
  }, []);

  const removeLine = useCallback((productId: number) => {
    setLines((current) => current.filter((l) => l.productId !== productId));
  }, []);

  const clear = useCallback(() => setLines([]), []);

  const subtotal = useMemo(
    () => lines.reduce((sum, l) => sum + l.unitPrice * l.quantity, 0),
    [lines],
  );

  return { lines, addProduct, setQuantity, removeLine, clear, subtotal };
}
```

```tsx
import { useEffect, useRef, useState } from "react";

export function ScannerInput({
  onScan,
  disabled,
}: {
  onScan: (code: string) => void;
  disabled?: boolean;
}) {
  const inputRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState("");

  // Keep focus on the scan field unless the operator is typing in another field.
  useEffect(() => {
    function refocus(event: MouseEvent) {
      const target = event.target as HTMLElement;
      if (target.closest("input, select, textarea, button, [role=dialog]")) return;
      inputRef.current?.focus();
    }
    document.addEventListener("click", refocus);
    inputRef.current?.focus();
    return () => document.removeEventListener("click", refocus);
  }, []);

  return (
    <input
      ref={inputRef}
      aria-label="Quét mã vạch hoặc nhập SKU"
      placeholder="Quét mã vạch hoặc nhập SKU rồi nhấn Enter"
      value={value}
      disabled={disabled}
      onChange={(e) => setValue(e.target.value)}
      onKeyDown={(e) => {
        if (e.key !== "Enter") return;
        e.preventDefault();
        const code = value.trim();
        setValue("");
        if (code) onScan(code);
      }}
      className="w-full rounded-md border px-4 py-3 text-lg"
    />
  );
}
```

```tsx
"use client";

import { daysBetween } from "@/lib/format/datetime";

export const MAX_REPORT_DAYS = 366;

/**
 * Reports require both ends, `to` is inclusive, and the span is capped at 366 days.
 * Validated here so an invalid range never becomes a 400 round trip.
 */
export function validateRange(from: string, to: string): string | null {
  if (!from || !to) return "Vui lòng chọn đầy đủ ngày bắt đầu và ngày kết thúc.";
  const span = daysBetween(from, to);
  if (span < 0) return "Ngày kết thúc phải sau hoặc bằng ngày bắt đầu.";
  if (span > MAX_REPORT_DAYS) return `Khoảng thời gian tối đa là ${MAX_REPORT_DAYS} ngày.`;
  return null;
}

export function DateRangePicker({
  from, to, onChange,
}: {
  from: string;
  to: string;
  onChange: (next: { from: string; to: string }) => void;
}) {
  const error = validateRange(from, to);

  return (
    <div className="space-y-1">
      <div className="flex flex-wrap items-end gap-3">
        <label className="space-y-1">
          <span className="block text-sm font-medium">Từ ngày</span>
          <input
            type="date" value={from}
            onChange={(e) => onChange({ from: e.target.value, to })}
            className="rounded-md border px-3 py-2"
          />
        </label>
        <label className="space-y-1">
          <span className="block text-sm font-medium">Đến ngày</span>
          <input
            type="date" value={to}
            onChange={(e) => onChange({ from, to: e.target.value })}
            className="rounded-md border px-3 py-2"
          />
        </label>
      </div>
      {error && <p role="alert" className="text-sm text-red-600">{error}</p>}
    </div>
  );
}
```

Each report page computes `const rangeError = validateRange(from, to)` and passes `enabled: rangeError === null` to its query, so no request is issued while the range is invalid.

## Task 24: Live integration, slice 1

The point of mock-first is lost if integration is deferred to the end. This task proves the switch works on the smallest possible surface, and is repeated per slice as the backend lands.

**Prerequisite:** the backend developer has `POST /auth/login`, `POST /auth/refresh` and `GET /products` running at a reachable URL.

**Files:**
- Create: `.env.live`, `docs/integration-log.md`
- Modify: `package.json`

**Interfaces:**
- Consumes: everything.
- Produces: `npm run dev:live`.

- [ ] **Step 1: Add the live environment and script**

Create `.env.live`:

```
NEXT_PUBLIC_API_MODE=live
NEXT_PUBLIC_API_BASE_URL=http://<backend-host>:<port>
```

Add to `package.json`:

```json
"dev:live": "env-cmd -f .env.live next dev"
```

Install `env-cmd` as a dev dependency. No application code changes — if any is needed, the `lib/api` boundary has leaked and that is the bug to fix first.

- [ ] **Step 2: Regenerate the contract types against the running backend**

From `/home/karpy/Lab/m1`:

```bash
npx openapi-typescript http://<backend-host>:<port>/api/v1/openapi.json -o api-types.ts
cd frontend && npx tsc --noEmit
```

Expected: no type errors. **Any error here is the early-warning signal working** — the contract moved, and the failing lines name exactly which call sites are affected. Fix them before continuing.

- [ ] **Step 3: Verify slice 1 against the live backend**

Run: `npm run dev:live`, then in the browser:

1. Log in with a real account. Expected: redirect by role, user name in the shell.
2. Open devtools, delete the `accessToken` value inside `localStorage["mini-store.session"]`, and trigger two list screens at once. Expected: exactly **one** `POST /auth/refresh` in the network tab, both requests succeed. If you see two refreshes and a logout, Task 4's single-flight guard has regressed.
3. Open `/products`. Expected: real data, working pagination and search.
4. Log in as a real cashier. Expected: no `costPrice` key in the `/products` response.

- [ ] **Step 4: Run the end-to-end suite against live**

Run: `PLAYWRIGHT_BASE_URL=http://localhost:3000 npm run test:e2e -- uc01`

Expected: UC-01 passes against the real backend. Data-dependent assertions (seeded names) will fail — that is expected, and the fix is to parameterise those tests with live credentials rather than to weaken them.

- [ ] **Step 5: Record divergences**

Create `docs/integration-log.md` and write down every difference found between mock and live: field shapes, rounding, document-number format, error codes, message wording. Each entry names the file to change and whether the mock or the frontend was wrong.

This list is the real output of the task. Semantic drift is precisely what the mock cannot catch, and finding it on a two-endpoint surface is vastly cheaper than finding it across fifteen screens.
